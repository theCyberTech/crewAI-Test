# `FileWriterTool`

## الوصف

تكتب `FileWriterTool` نصًا في ملف. تُنشأ المجلدات المفقودة تلقائيًا. الترميز الافتراضي هو UTF-8. تكتب الأداة نصًا فقط، وليس ملفات ثنائية.

تبقى عمليات الكتابة داخل `base_dir`، الذي يكون افتراضيًا مجلد العمل الحالي.

## التثبيت

```shell
pip install 'crewai[tools]'
```

## مثال

```python Code
from crewai_tools import FileWriterTool

file_writer_tool = FileWriterTool()

result = file_writer_tool.run(
    filename='example.txt',
    content='This is a test content.',
    directory='test_directory',
)
print(result)
```

## المعاملات

يوفّرها الوكيل في وقت التشغيل:

- `filename`: اسم الملف المراد كتابته، نسبةً إلى `directory`. يمكن أن يتضمن مجلدات فرعية، وتُنشأ إن لم تكن موجودة.
- `content`: النص المراد كتابته.
- `directory` (اختياري): المجلد الذي تتم الكتابة إليه. يُحل المسار النسبي داخل المجلد المسموح للأداة (`base_dir` عند تعيينه، وإلا مجلد العمل الحالي) ويُعيَّن افتراضيًا إلى جذر ذلك المجلد (`./`). يُنشأ إن لم يكن موجودًا.
- `overwrite` (اختياري): ما إذا كان يجب استبدال ملف موجود. يقبل `true`/`false` (وكذلك `yes`/`no`، `on`/`off`، `1`/`0`). الافتراضي هو `false`، وفي هذه الحالة تُرجع الأداة خطأً بدل استبدال الملف.

تُعيَّن هذه عند إنشاء الأداة:

- `base_dir` (اختياري): المجلد الذي يجب أن تبقى عمليات الكتابة داخله. الافتراضي هو مجلد العمل الحالي وقت الكتابة. يُحل المسار الذي تعيّنه عند إنشاء الأداة، لذا لا ينقل تغيير لاحق لمجلد العمل هذا الحد.
- `encoding` (اختياري): ترميز النص المستخدم لكتابة الملف. الافتراضي هو `utf-8`.

## المسارات المسموح بها

لأن `directory` و`filename` يختارهما عادةً نموذج لغوي في وقت التشغيل، تقتصر عمليات الكتابة على sandbox:

- يجب أن يكون `directory` المحلول داخل `base_dir` (مجلد العمل الحالي وقت الكتابة إن لم تعيّن `base_dir`).
- يجب أن يكون مسار الملف المحلول داخل ذلك `directory`.
- تُحل مقاطع `..` والمسارات المطلقة والروابط الرمزية قبل كلا الفحصين، لذا لا يمكن استخدامها للخروج.

للسماح للوكيل بالكتابة خارج مجلد العمل، وجّه `base_dir` إلى الشجرة المستهدفة:

```python Code
file_writer_tool = FileWriterTool(base_dir='/var/output')
```

<Note>
سابقًا، كان بإمكان `directory` المطلق الكتابة في أي مكان تملك العملية صلاحية الكتابة إليه. إذا اعتمدت على ذلك، عيّن `base_dir` إلى الشجرة التي تريد السماح بها. تعيين `CREWAI_TOOLS_ALLOW_UNSAFE_PATHS=true` يعيد السلوك القديم، لكنه يعطّل فحوصات المسار وURL على مستوى العملية لكل أدوات crewai-tools، بما في ذلك حماية SSRF على أدوات جلب عناوين URL. فضّل `base_dir`. على العمال المُدارين، عيّن `CREWAI_TOOLS_FORCE_SAFE_PATHS=true` حتى لا يتمكن مستأجر من تعطيل تلك الفحوصات.
</Note>
