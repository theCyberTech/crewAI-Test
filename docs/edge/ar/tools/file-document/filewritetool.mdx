# `FileWriterTool`

## الوصف

تكتب `FileWriterTool` نصًا في ملف.

تُنشئ المجلدات المفقودة.
تستخدم UTF-8 افتراضيًا.
تكتب نصًا فقط. لا تكتب ملفات ثنائية.

تبقى عمليات الكتابة داخل مجلد آمن. افتراضيًا، هذا المجلد هو مجلد العمل الحالي. مرّر `base_dir` لاستخدام مجلد مختلف.

## التثبيت

```shell
pip install 'crewai[tools]'
```

## مثال

```python Code
from crewai_tools import FileWriterTool

file_writer_tool = FileWriterTool()

result = file_writer_tool.run(
    filename='example.txt',
    content='This is a test content.',
    directory='test_directory',
)
print(result)
```

## المعاملات

يمرّرها الوكيل عند التشغيل:

- `filename`: اسم الملف، نسبةً إلى `directory`. يمكنك تضمين مجلدات في الاسم، مثل `reports/weekly.txt`. تُنشأ المجلدات المفقودة.
- `content`: النص المراد كتابته.
- `directory` (اختياري): المجلد الذي تتم الكتابة إليه. يُحل المسار النسبي داخل المجلد المسموح للأداة (`base_dir` إذا عيّنته، وإلا مجلد العمل الحالي). الافتراضي هو جذر ذلك المجلد (`./`). تُنشأ المجلدات المفقودة.
- `overwrite` (اختياري): استبدل الملف إذا كان موجودًا. مرّر `true` أو `false`. تعمل أيضًا صيغ نعم/لا الأخرى (`yes`/`no`، `on`/`off`، `1`/`0`). الافتراضي هو `false`. إذا كان الملف موجودًا و`overwrite` هو `false`، تُرجع الأداة خطأً ولا تغيّر الملف.

تعيّن هذه عند إنشاء الأداة:

- `base_dir` (اختياري): المجلد الذي يجب أن تبقى عمليات الكتابة داخله. الافتراضي هو مجلد العمل الحالي وقت الكتابة. إذا عيّنت مسارًا، تثبّته الأداة عند إنشائها. تغيير مجلد العمل لاحقًا لا ينقله.
- `encoding` (اختياري): كيفية ترميز النص. الافتراضي هو `utf-8`.

## المسارات المسموح بها

غالبًا ما يختار الوكيل `directory` و`filename` في وقت التشغيل. تمنع الأداة المسارات التي تغادر المجلد الآمن.

- يجب أن يكون `directory` النهائي داخل `base_dir`. إذا لم تعيّن `base_dir`، فهذا هو مجلد العمل الحالي وقت الكتابة.
- يجب أن يكون مسار الملف النهائي داخل ذلك `directory`.
- تحل الأداة مقاطع `..` والمسارات المطلقة والروابط الرمزية قبل الفحص. لا يمكن استخدامها لمغادرة المجلد الآمن.

للسماح للوكيل بالكتابة تحت مجلد مختلف، عيّن `base_dir`:

```python Code
file_writer_tool = FileWriterTool(base_dir='/var/output')
```

<Note>
كانت الإصدارات الأقدم تسمح لـ `directory` المطلق بالكتابة في أي مكان تستطيع العملية الكتابة إليه. إذا كنت تحتاج ذلك، عيّن `base_dir` إلى المجلد الذي تريد السماح به.

`CREWAI_TOOLS_ALLOW_UNSAFE_PATHS=true` يعطّل هذه الفحوصات لكل أدوات crewai-tools في العملية. يعطّل أيضًا فحوصات أمان عناوين URL. فضّل `base_dir`. على العمال المشتركين، عيّن `CREWAI_TOOLS_FORCE_SAFE_PATHS=true` حتى لا يتمكن مستخدم من تعطيل الفحوصات.
</Note>
