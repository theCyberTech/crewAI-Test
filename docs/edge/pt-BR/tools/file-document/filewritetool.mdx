# `FileWriterTool`

## Descrição

O `FileWriterTool` escreve texto em um arquivo.

Ele cria pastas que não existem.
Ele usa UTF-8 por padrão.
Ele escreve só texto. Ele não escreve arquivos binários.

As escritas ficam dentro de uma pasta segura. Por padrão, essa pasta é o diretório de trabalho atual. Passe `base_dir` para usar outra pasta.

## Instalação

```shell
pip install 'crewai[tools]'
```

## Exemplo

```python Code
from crewai_tools import FileWriterTool

file_writer_tool = FileWriterTool()

result = file_writer_tool.run(
    filename='example.txt',
    content='This is a test content.',
    directory='test_directory',
)
print(result)
```

## Argumentos

O agente passa estes quando executa:

- `filename`: Nome do arquivo, relativo a `directory`. Você pode incluir pastas no nome, como `reports/weekly.txt`. Pastas ausentes são criadas.
- `content`: O texto a escrever.
- `directory` (opcional): Pasta em que escrever. Um caminho relativo fica dentro da pasta permitida da ferramenta (`base_dir` se você definir; senão, o diretório de trabalho atual). O padrão é a raiz dessa pasta (`./`). Pastas ausentes são criadas.
- `overwrite` (opcional): Substitui o arquivo se ele já existir. Passe `true` ou `false`. Outras formas de sim/não também funcionam (`yes`/`no`, `on`/`off`, `1`/`0`). O padrão é `false`. Se o arquivo existir e `overwrite` for `false`, a ferramenta retorna um erro e não altera o arquivo.

Você define estes ao criar a ferramenta:

- `base_dir` (opcional): A pasta em que as escritas devem permanecer. O padrão é o diretório de trabalho atual no momento da escrita. Se você definir um caminho, a ferramenta o trava na criação. Mudar o diretório de trabalho depois não o move.
- `encoding` (opcional): Como codificar o texto. O padrão é `utf-8`.

## Caminhos permitidos

Um agente costuma escolher `directory` e `filename` em tempo de execução. A ferramenta bloqueia caminhos que saem da pasta segura.

- O `directory` final deve estar dentro de `base_dir`. Se você não definir `base_dir`, isso é o diretório de trabalho atual no momento da escrita.
- O caminho final do arquivo deve estar dentro desse `directory`.
- A ferramenta resolve `..`, caminhos absolutos e symlinks antes de verificar. Eles não podem ser usados para sair da pasta segura.

Para permitir que um agente escreva em outra pasta, defina `base_dir`:

```python Code
file_writer_tool = FileWriterTool(base_dir='/var/output')
```

<Note>
Versões antigas deixavam um `directory` absoluto escrever em qualquer lugar em que o processo pudesse escrever. Se você precisa disso, defina `base_dir` para a pasta que deseja permitir.

`CREWAI_TOOLS_ALLOW_UNSAFE_PATHS=true` desliga essas verificações para todas as ferramentas crewai-tools no processo. Isso também desliga as verificações de segurança de URL. Prefira `base_dir`. Em workers compartilhados, defina `CREWAI_TOOLS_FORCE_SAFE_PATHS=true` para que um usuário não possa desligar as verificações.
</Note>
