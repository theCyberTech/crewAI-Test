# `FileWriterTool`

## 설명

`FileWriterTool`은 파일에 텍스트를 씁니다.

없는 폴더는 만듭니다.
기본값으로 UTF-8을 사용합니다.
텍스트만 씁니다. 바이너리 파일은 쓰지 않습니다.

쓰기는 안전한 폴더 안에만 남습니다. 기본적으로 그 폴더는 현재 작업 디렉터리입니다. 다른 폴더를 쓰려면 `base_dir`을 전달하세요.

## 설치

```shell
pip install 'crewai[tools]'
```

## 예시

```python Code
from crewai_tools import FileWriterTool

file_writer_tool = FileWriterTool()

result = file_writer_tool.run(
    filename='example.txt',
    content='This is a test content.',
    directory='test_directory',
)
print(result)
```

## 인자

에이전트가 실행할 때 넘기는 값:

- `filename`: `directory`를 기준으로 한 파일 이름입니다. 이름에 폴더를 넣을 수 있습니다. 예: `reports/weekly.txt`. 없는 폴더는 만들어집니다.
- `content`: 쓸 텍스트입니다.
- `directory` (선택 사항): 쓸 폴더입니다. 상대 경로는 도구가 허용한 폴더 안에 있습니다(`base_dir`을 설정한 경우 그 값, 아니면 현재 작업 디렉터리). 기본값은 그 폴더의 루트(`./`)입니다. 없는 폴더는 만들어집니다.
- `overwrite` (선택 사항): 파일이 이미 있으면 덮어씁니다. `true` 또는 `false`를 전달하세요. 다른 yes/no 표기도 됩니다(`yes`/`no`, `on`/`off`, `1`/`0`). 기본값은 `false`입니다. 파일이 있고 `overwrite`가 `false`이면 도구는 오류를 반환하고 파일을 바꾸지 않습니다.

도구를 만들 때 설정하는 값:

- `base_dir` (선택 사항): 쓰기가 머물러야 하는 폴더입니다. 기본값은 쓰는 시점의 현재 작업 디렉터리입니다. 경로를 설정하면 도구를 만들 때 그 경로를 고정합니다. 나중에 작업 디렉터리를 바꿔도 이동하지 않습니다.
- `encoding` (선택 사항): 텍스트를 인코딩하는 방식입니다. 기본값은 `utf-8`입니다.

## 허용 경로

에이전트는 실행 시 `directory`와 `filename`을 고르는 경우가 많습니다. 도구는 안전한 폴더를 벗어나는 경로를 막습니다.

- 최종 `directory`는 `base_dir` 안에 있어야 합니다. `base_dir`을 설정하지 않으면, 이는 쓰는 시점의 현재 작업 디렉터리입니다.
- 최종 파일 경로는 그 `directory` 안에 있어야 합니다.
- 도구는 검사하기 전에 `..`, 절대 경로, 심볼릭 링크를 해석합니다. 이를 써서 안전한 폴더를 벗어날 수 없습니다.

다른 폴더 아래에 쓰게 하려면 `base_dir`을 설정하세요:

```python Code
file_writer_tool = FileWriterTool(base_dir='/var/output')
```

<Note>
이전 버전에서는 절대 `directory`가 프로세스가 쓸 수 있는 아무 곳에나 쓸 수 있었습니다. 그 동작이 필요하면 허용할 폴더로 `base_dir`을 설정하세요.

`CREWAI_TOOLS_ALLOW_UNSAFE_PATHS=true`는 프로세스의 모든 crewai-tools 도구에서 이 검사를 끕니다. URL 안전 검사도 꺼집니다. `base_dir`을 쓰세요. 공유 워커에서는 `CREWAI_TOOLS_FORCE_SAFE_PATHS=true`를 설정해 사용자가 검사를 끄지 못하게 하세요.
</Note>
